# Vendor Performance Analysis

This project analyzes vendor sales, purchase, inventory turnover, and profitability data to identify underperforming brands, vendor dependency risks, bulk purchase cost benefits, and pricing opportunities.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn

## Key Objectives
- Identify low-performing and high-margin brands
- Analyze vendor contribution to sales and purchases
- Evaluate inventory turnover and unsold inventory
- Assess impact of bulk purchasing on unit cost

## Key Insights
- A small number of vendors contribute the majority of purchases
- Bulk purchasing significantly reduces unit cost
- Some vendors have high margins but low sales volume
- Slow-moving inventory ties up significant capital

## Outcome
The analysis provides actionable insights to optimize pricing, inventory management, and vendor strategy.
